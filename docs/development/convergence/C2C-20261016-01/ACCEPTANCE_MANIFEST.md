## Numerical oracle definitions and false-positive controls

`pi=acos(-1)` and every mandated refinement uses x[0,1]. Norms are evaluated over **all returned nodes at final time**: `E_inf=max(abs(error))`, `E_2=sqrt(dx*sum(error²))`; rates are `log2(coarse/fine)` for pairs 0→1 and1→2, separately for each norm. Zero/nonpositive/nonfinite errors cannot pass a rate. Finest-level thresholds are checked in addition to rates. Endpoints are checked against actual BC data at t1, not against a fitted function. All four coefficient/source callbacks are explicit in the required manufactured/refinement/heat fixtures. Only the stated defaults fixture and §6 sample intentionally use defaults. Grid counts, theta, times, formulas and limits are embedded in AS-04 and in the matrix above.

For the supplemental mixed fixture, the source is `0.4+t²+0.3x`; a/b/c are the same linear formulas as the all-terms fixture; IC is `1+x+x²`; left=`1+2t+0.25x`, right=`2-t+0.5x`. The dense oracle builds the specified tridiagonal operator into a full matrix, then independently solves with pivoted long-double Gaussian elimination. It does not reproduce Thomas. Its expected small-grid vectors are printed and stored in EV-01 before production exists. Analytic manufactured solutions, exact one-row rational expression, and discrete sine amplification form separate oracles so a shared assembly mistake in the dense oracle cannot alone make the suite pass.

Failure tests snapshot double object representations, preserving NaN as well as ordinary values, and check every coefficient plus RHS after failure. Merely throwing the wrong exception, silently returning no assertion, or producing NaN does not pass. Callback sample coverage compares sets, leaving allowed repetition and evaluation order unconstrained; exceptions outside the required set deliberately fail if invoked. Exact user exception subclass/payload tests prevent exception wrapping from masquerading as validation. Runtime checks supplement static requirements; tests do not imply that unexecuted branches or absence of unauthorized methods have been proven.
